# Lista de tarefas

Projeto de estudo com Next.js, TypeScript e Jest. Dá para adicionar tarefas e acompanhar a quantidade na lista. As tarefas adicionadas não ficam salvas ao atualizar a página.

## Instalação

É preciso ter o Node.js e o npm instalados.

Abra o terminal na pasta `with-jest` e instale as dependências:

```bash
npm install
```

## Como rodar

```bash
npm run dev
```

Depois, acesse [localhost:3000](http://localhost:3000) no navegador.

Para parar, use `Ctrl + C` no terminal.

## Testes

Para rodar os testes:

```bash
npm test
```

Para deixar os testes rodando enquanto altera o código:

```bash
npm run test:watch
```
